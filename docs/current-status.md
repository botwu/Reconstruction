## 框架与模块预期

完整 session → 任务边界与语义解析 → 按 domain 恢复初态 → 独立充分性检查 → Harbor 交付与真实求解 → 按实际失败原因反馈。

| 模块 | 产物与判断依据 |
| --- | --- |
| 原文与工具解析 | system、工具定义、参数、返回、报错、补丁、历史回答和子 agent 输出完整保留；派生解释能定位并逐值核对原文 |
| 任务提取 | 恢复用户目标与必要历史；原助手选择的文件名和实现方案不能自动成为用户要求 |
| terminal 初态 | 恢复源码、依赖、数据与执行条件，保留原待修问题，不预装目标实现；运行相关业务链并核对源码来源 |
| search 环境 | 交付原捕获、真实补充资料和所需检索能力；保留版本、来源及历史回答/片段/摘要/全文/OCR 的证据边界 |
| 充分性检查 | 逐项判断任务是否可解及初态是否忠实，区分重建缺口、原任务缺陷和无关问题 |
| 交付与可选评分 | 共用 Harbor 导出层。显式 --disable-verification 独立交付任务环境并执行未评分求解；自动文件评分另行生成并实际校准验证器 |
| rollout 与反馈 | 核对实际输入、捕获、输出与内容。环境缺口交回 researcher；资料已供给而 solver 答错时保留答错，不能借改环境掩盖 |

domain 由调用方指定为 search 或 terminal。harness（Codex、Hermes、Claude Code 等）决定工具协议解释，不按 harness 复制重建管线。timeline 用于来源、时序和保守初态种子，不机械执行旧命令或取代模型语义理解。

重建者首次请求直接包含完整 SOURCE_SESSION，后续沿同一会话接收实际反馈。原文存在或可读取不等于已经利用，必须核实际读取、恢复差异及执行结果。AgenticFoundry 仅作只读参考，不作为运行依赖。
